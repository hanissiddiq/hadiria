# hadiria
Hadiria adalah sistem informasi manajemen kehadiran dan personalia modern yang dibangun khusus sebagai wujud pembaruan (re-engineering) dari platform SmartPPNPN. Aplikasi ini dirancang ulang untuk menghadirkan performa yang lebih cepat, antarmuka yang lebih intuitif, serta pengelolaan data yang jauh lebih aman dan efisien.
